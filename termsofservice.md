# Deek Discord Bot

Deek is a Discord bot designed to provide moderation, utility, and fun features for Discord servers.

## Features

* Moderation commands
* Utility commands
* Server management tools
* Custom configuration

## Invite

You can invite Deek to your server using the bot invite link provided by the developer.

## Support

If you encounter bugs or issues, open an issue in this repository.
