Deek Discord Bot – Repository Policy
# 1. Overview

Deek is a Discord bot designed to provide moderation, utility, and community features for Discord servers. This repository contains the source code, documentation, and configuration files related to the bot.

By contributing to or using this repository, you agree to follow the policies listed below.

# 2. Acceptable Use

The Deek bot and its source code may not be used for:

Harassment, abuse, or targeting individuals or communities

Violating Discord’s Terms of Service

Illegal activities

Malicious automation (spam, raids, etc.)

Data harvesting without consent

Users and developers must follow the rules outlined in:

Discord Developer Terms

Discord Community Guidelines

# 3. Contributions

Contributions are welcome. To contribute:

Fork the repository

Create a new branch

Make your changes

Submit a pull request

Contribution Rules

Write clear and readable code

Follow the existing coding style

Test your changes before submitting

Document new features when necessary

Pull requests that contain malicious code, spam, or unrelated changes will be rejected.

# 4. Security Policy

If you discover a security vulnerability, do not open a public issue.

Instead:

Report it privately to the repository maintainers.

Provide details and steps to reproduce the issue.

Security reports will be reviewed as quickly as possible.

# 5. Privacy & Data Usage

The Deek bot may process limited Discord data such as:

User IDs

Server IDs

Command usage

Configuration settings

This data is only used for bot functionality and is not sold or shared with third parties.

Sensitive data such as:

Tokens

API keys

Database credentials

must never be committed to the repository.
